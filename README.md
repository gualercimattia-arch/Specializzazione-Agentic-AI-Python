# Specializzazione Agentic AI – Python

Repository del percorso di specializzazione master in **Agentic AI con Python**.
Contiene esercitazioni, progetti e materiale di studio sviluppati durante il corso.

## Struttura

```
Specializzazione-Agentic-AI-Python/
├── esercitazioni/   # esercizi svolti durante le lezioni
├── progetti/        # progetti completi e lavori finali
├── appunti/         # note e materiale di studio
└── requirements.txt # dipendenze Python
```

## Requisiti

- Python 3.11 o superiore
- pip

## Installazione

```bash
git clone https://github.com/gualercimattia-arch/Specializzazione-Agentic-AI-Python.git
cd Specializzazione-Agentic-AI-Python
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate
pip install -r requirements.txt
```
